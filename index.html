LINEAR SEARCH

💡 KONSEP: PROSES LINEAR SEARCH

Linear Search menyemak setiap item dalam senarai satu persatu bermula dari permulaan (indeks 0) sehingga item ditemui atau senarai habis.

SEMAK ITEM PERTAMA → BANDINGKAN DENGAN T → JIKA SAMA = JUMPA → JIKA TIDAK = GERAK KE SEBELAH
Pilih Senario Carian

Senarai: [10, 82, 5, 18, 27]

🎮 SIMULASI LINEAR SEARCH

Senarai: [10, 82, 5, 18, 27] • Cari T = 18
Pemboleh ubah i 0
Nilai Carian (T) 18
Saiz Senarai (n) 5
Status Semasa

Tekan '▶ Seterusnya' untuk mula simulasi Linear Search.

📋 PSEUDOKOD LINEAR SEARCH (RUJUKAN RASMI)

1. Mula
2. Setkan senarai L = [10, 82, 5, 18, 27]
3. Isytihar pemboleh ubah i, n, T
4. Setkan n = 5
5. Setkan i = 0
6. Masukkan nilai carian T
7. for i < n
7.1 Jika L[i] == T
7.1.1 Papar "Item ada dalam senarai"
7.1.2 Tamat carian
7.2 Jika tidak
7.2.1 Kira i = i + 1
7.3 Tamat jika
8. Jika i == n
8.1 Papar "Item tiada dalam senarai"
8.2 Tamat jika
9. Tamat

FASA 0 • MODUL 0.2

BINARY SEARCH

💡 KONSEP: PROSES BINARY SEARCH

Binary Search mencari nilai dengan melihat nombor di tengah terlebih dahulu. Algoritma ini membahagikan kawasan carian kepada bahagian yang lebih kecil.

CARI DI TENGAH → BANDINGKAN → BUANG SEBAHAGIAN → CARI SEMULA → ULANG

⚠️ PENTING: SYARAT BINARY SEARCH

Senarai mestilah disusun terlebih dahulu (tertib menaik atau menurun) sebelum algoritma Binary Search boleh dijalankan.

Contoh Senarai Tersusun: [10] [20] [30] [40] [50] [60] [70]
Pilih Senario Carian

Senarai: [10, 20, 30, 40, 50, 60, 70]

🎮 SIMULASI BINARY SEARCH

Senarai: [10, 20, 30, 40, 50, 60, 70] • Cari T = 60
Indeks i 0
Indeks j 6
Indeks m (Tengah) -
Nilai Carian (T) 60
Nilai Tengah L[m] -
Status Semasa

Tekan '▶ Seterusnya' untuk mula simulasi Binary Search.

📋 PSEUDOKOD BINARY SEARCH (RUJUKAN RASMI)

1. Mula
2. Item-item dalam senarai yang diberi telah diisi mengikut urutan menaik. (L = [10, 20, 30, 40, 50, 60, 70])
3. Isytihar pemboleh ubah i, j, m, n, T
4. Setkan i = 0, j = n - 1 (6)
5. Masukkan nilai carian T
6. while i <= j
6.1 Lihat item yang berada di tengah senarai: m = INT((i + j) / 2)
6.2 Bandingkan item carian T dengan item yang berada di tengah L[m]
6.3 Jika T == L[m]
6.3.1 Papar "Item ada dalam senarai pada kedudukan m"
6.3.2 Tamat carian
6.4 Jika T < L[m]
6.4.1 Abaikan item di tengah dan item selepasnya (j = m - 1)
6.5 Jika T > L[m]
6.5.1 Abaikan item di tengah dan item sebelumnya (i = m + 1)
6.6 Tamat jika
7. Jika i > j
7.1 Papar "Item tiada dalam senarai"
7.2 Tamat jika
8. Tamat

FASA 0 • MODUL 0.3

BUBBLE SORT MENAIK

💡 KONSEP: PROSES BUBBLE SORT

Algoritma Bubble Sort berfungsi dengan membandingkan nombor yang bersebelahan dan menukar kedudukannya jika nombor di sebelah kiri lebih besar daripada nombor di sebelah kanan.

BANDINGKAN JIRAN → JIKA NOMBOR KIRI > KANAN → TUKAR → ULANG

🧠 PERANAN PEMBOLEH UBAH temp

Pemboleh ubah temp diambil daripada perkataan temporary (sementara). Ia digunakan untuk menyimpan satu nilai buat sementara ketika dua nombor ditukar kedudukannya supaya tiada data yang hilang.

LANGKAH 1 temp = nilai kiri

Simpan nombor kiri ke temp.

LANGKAH 2 nilai kiri = nilai kanan

Pindahkan nilai kanan ke kiri.

LANGKAH 3 nilai kanan = temp

Masukkan temp ke kanan.

🎮 SIMULASI BUBBLE SORT

Pusingan 1 • Senarai: [6, 1, 4, 2, 8]
Pemboleh ubah i 0
Pemboleh ubah j 0
Pemboleh ubah n 5
Pemboleh ubah temp 0
Status Semasa

Tekan '▶ Seterusnya' untuk mula simulasi Bubble Sort Menaik.

📋 PSEUDOKOD BUBBLE SORT (SUSUNAN MENAIK)

1. Mula
2. Setkan senarai L = [6, 1, 4, 2, 8]
3. Isytihar pemboleh ubah i, j, n, temp
4. Setkan n = 5
5. Setkan i = 0
6. Setkan temp = 0
7. for i < n - 1
7.1 Setkan j = 0
7.2 for j < n - i - 1
7.2.1 Jika nombor kiri > nombor kanan
7.2.1.1 temp = L[j]
7.2.1.2 L[j] = L[j+1]
7.2.1.3 L[j+1] = temp
7.2.2 Tamat jika
7.2.3 Kira j = j + 1
7.3 Kira i = i + 1
8. Papar senarai [1, 2, 4, 6, 8]
9. Tamat

BUBBLE SORT MENURUN

💡 KONSEP: PROSES BUBBLE SORT MENURUN

Bagi susunan menurun (daripada besar ke kecil), pertukaran berlaku jika nombor di sebelah kiri lebih kecil daripada nombor di sebelah kanan (L[j] < L[j+1]). Nombor yang lebih kecil akan 'tenggelam' atau ditolak ke sebelah kanan.

BANDINGKAN JIRAN → JIKA NOMBOR KIRI < KANAN → TUKAR → ULANG

🧠 PERANAN PEMBOLEH UBAH temp DALAM SUSUNAN MENURUN

Pemboleh ubah temp berfungsi sama seperti dalam susunan menaik iaitu menyimpan nilai sementara semasa proses pertukaran kedudukan dua nombor bersebelahan.

LANGKAH 1 temp = L[j]

Simpan nombor kiri ke temp.

LANGKAH 2 L[j] = L[j+1]

Pindahkan nilai kanan ke kiri.

LANGKAH 3 L[j+1] = temp

Masukkan temp ke kanan.

3. Isytihar pemboleh ubah i, j, n, temp
4. Setkan n = 5
5. Setkan i = 0

FASA 0 • MODUL 0.5

BUCKET SORT

💡 KONSEP: PROSES BUCKET SORT

Bucket Sort membahagikan item kepada beberapa baldi mengikut julat yang ditetapkan. Selepas semua item dimasukkan, item dalam setiap baldi diisih dan semua baldi dicantumkan semula menjadi satu senarai.

WUJUDKAN BALDI → MASUKKAN ITEM → ISIH SETIAP BALDI → CANTUMKAN

🧠 IDEA UTAMA

Item tidak terus disusun semuanya sekali gus. Item dikelompokkan dahulu mengikut baldi, kemudian setiap baldi diisih sebelum semua item dicantumkan.

Senario Simulasi

Senarai: [23, 7, 15, 3, 28, 18]

Baldi 1: 1–10  •  Baldi 2: 11–20  •  Baldi 3: 21–30

Senarai simulasi ini sengaja berbeza daripada contoh senarai dalam pseudokod rujukan supaya murid memahami proses, bukan menghafal contoh.

n 6

🪣 Baldi 3

Tekan '▶ Seterusnya' untuk mula simulasi Bucket Sort.

📋 PSEUDOKOD BUCKET SORT (RUJUKAN GURU)

1. Mula
2. Setkan senarai senarai = [23, 7, 15, 3, 28, 18]
3. Isytihar pemboleh ubah i, j, n, nB, senaraiBaharu
4. Setkan n = 6
5. Setkan nB = 3
6. Tentukan julat bagi setiap baldi
7. Wujudkan baldi kosong
8. Masukkan item ke dalam baldi
9. Setkan i = 0
10. for i < n
10.1 Masukkan senarai[i] ke dalam baldi
10.2 Kira i = i + 1
11. Setkan j = 0
12. for j < nB
12.1 Jika Baldi[j] kosong
12.2 Jika tidak
12.2.1 Isih item di dalam baldi (Bubble Sort)
12.2.2 Kira j = j + 1
13. Cantum dan masukkan item ke senaraiBaharu[]
14. Papar senaraiBaharu[]
15. Tamat

Pemboleh ubah temp diambil daripada perkataan temporary (sementara). Ia digunakan untuk menyimpan satu nilai buat sementara ketika dua nombor ditukar kedudukannya supaya tiada data yang hilang.

LANGKAH 1 temp = nilai kiri

Simpan nombor kiri ke temp.

LANGKAH 2 nilai kiri = nilai kanan

Pindahkan nilai kanan ke kiri.

LANGKAH 3 nilai kanan = temp

Masukkan temp ke kanan.

📋 PSEUDOKOD BUBBLE SORT (SUSUNAN MENAIK)

1. Mula
2. Setkan senarai L = [6, 1, 4, 2, 8]
3. Isytihar pemboleh ubah i, j, n, temp
4. Setkan n = 5
5. Setkan i = 0
6. Setkan temp = 0
7. for i < n - 1
7.1 Setkan j = 0
7.2 for j < n - i - 1
7.2.1 Jika nombor kiri > nombor kanan
7.2.1.1 temp = L[j]
7.2.1.2 L[j] = L[j+1]
7.2.1.3 L[j+1] = temp
7.2.2 Tamat jika
7.2.3 Kira j = j + 1
7.3 Kira i = i + 1
8. Papar senarai [1, 2, 4, 6, 8]
9. Tamat

BUBBLE SORT MENURUN

💡 KONSEP: PROSES BUBBLE SORT MENURUN

Bagi susunan menurun (daripada besar ke kecil), pertukaran berlaku jika nombor di sebelah kiri lebih kecil daripada nombor di sebelah kanan (L[j] < L[j+1]). Nombor yang lebih kecil akan 'tenggelam' atau ditolak ke sebelah kanan.

BANDINGKAN JIRAN → JIKA NOMBOR KIRI < KANAN → TUKAR → ULANG

🧠 PERANAN PEMBOLEH UBAH temp DALAM SUSUNAN MENURUN

Pemboleh ubah temp berfungsi sama seperti dalam susunan menaik iaitu menyimpan nilai sementara semasa proses pertukaran kedudukan dua nombor bersebelahan.

LANGKAH 1 temp = L[j]

Simpan nombor kiri ke temp.

LANGKAH 2 L[j] = L[j+1]

Pindahkan nilai kanan ke kiri.

LANGKAH 3 L[j+1] = temp

Masukkan temp ke kanan.

BUCKET SORT

💡 KONSEP: PROSES BUCKET SORT

Bucket Sort membahagikan item kepada beberapa baldi mengikut julat yang ditetapkan. Selepas semua item dimasukkan, item dalam setiap baldi diisih dan semua baldi dicantumkan semula menjadi satu senarai.

WUJUDKAN BALDI → MASUKKAN ITEM → ISIH SETIAP BALDI → CANTUMKAN

🧠 IDEA UTAMA

Item tidak terus disusun semuanya sekali gus. Item dikelompokkan dahulu mengikut baldi, kemudian setiap baldi diisih sebelum semua item dicantumkan.

Senario Simulasi

Senarai: [23, 7, 15, 3, 28, 18]

Baldi 1: 1–10  •  Baldi 2: 11–20  •  Baldi 3: 21–30

Senarai simulasi ini sengaja berbeza daripada contoh senarai dalam pseudokod rujukan supaya murid memahami proses, bukan menghafal contoh.
